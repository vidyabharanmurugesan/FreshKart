1. PROJECT ARCHITECTURE OVERVIEW
================================

High-Level Architecture:
The application follows a three-tier architecture with frontend, backend, and database layers.

Frontend Layer:
- React-based user interfaces for four user roles: Buyer, Seller, Admin, and Delivery Partner
- Separate interfaces for two business domains: Food and Grocery
- Real-time communication via Socket.io client
- HTTP communication via Axios for API calls

Backend Layer:
- Flask-based REST API with JWT authentication
- Socket.io server for real-time WebSocket communication
- Business logic controllers for each module
- Route blueprints for organized API endpoints

Database Layer:
- Firebase Firestore as primary NoSQL database
- Local JSON files as fallback for offline development
- Automatic fallback mechanism for reliability

Communication Flow:
Frontend sends HTTP requests to Flask backend for CRUD operations
Frontend connects to Socket.io server for real-time updates
Backend communicates with Firebase for data persistence
Socket.io broadcasts events to connected clients

- shop_address: Physical address
- gps_location: GPS coordinates
- shop_license: FSSAI license number
- gstin: GST identification number
- bank_account_details: Bank account information
- cuisine_type: Type of cuisine (for food)
- operating_hours: Business operating hours

Delivery-specific Fields:
- vehicle_number: Vehicle registration number
- vehicle_type: Vehicle type (bike, car)
- driving_license_number: License number
- driving_license_image: License image URL
- profile_photo: Profile picture URL
- aadhaar_card: Aadhaar card details
- current_address: Current residence address
- city: City name
- state: State name
- pincode: Postal code
- bank_account_holder_name: Account holder name
- bank_name: Bank name
- bank_account_number: Account number
- bank_ifsc_code: IFSC code
- emergency_contact_name: Emergency contact name
- emergency_contact_phone: Emergency contact phone
- emergency_contact_relationship: Relationship with emergency contact
- category_manager_approval: Approval status

Orders Collection Structure:
- order_id: Unique order identifier (ORD-YYYY-XXXX format)
- buyer_id: Buyer user identifier
- seller_id: Seller user identifier
- delivery_partner_id: Delivery partner identifier
- items: Array of order items with product details
- total_amount: Final order amount including all charges
- gst_amount: GST amount calculated
- discount: Applied discount amount
- delivery_charges: Delivery fee
- packaging_charges: Packaging fee
- platform_fee: Platform commission fee
- address: Delivery address object with street, city, state, pincode
- status: Order status (pending, accepted, assigned_to_delivery, picked_up, delivered, cancelled)
- payment_method: Payment method (cod, online)
- payment_status: Payment status (paid, unpaid, refunded)
- domain: Business domain (food or grocery)
- location: Current delivery location with latitude and longitude
- tracking_number: Tracking identifier
- delivery_date: Expected delivery date and time
- chat_messages: Array of chat messages
- created_at: Order creation timestamp
- updated_at: Last update timestamp

Products Collection Structure:
- product_id: Unique product identifier
- seller_id: Seller user identifier
- name: Product name
- description: Product description
- price: Selling price
- mrp: Maximum retail price (for grocery)
- discount: Discount percentage
- category: Product category
- subcategory: Product subcategory
- domain: Business domain (food or grocery)
- stock_count: Available stock quantity
- in_stock: Stock availability status
- image_url: Product image URL

Food-specific Fields:
- dietary_tag: Dietary preference (veg, non-veg, egg)
- variants: Array of size variants with name and price
- addons: Array of add-ons with name and price
- spice_level: Spice level (mild, medium, hot)
- allergen_info: Allergy warning information
- is_cake: Cake product flag
- cake_variants: Cake weight variants
- is_combo: Combo meal flag
- combo_items: Combo meal items

Grocery-specific Fields:
- brand_name: Brand name
- pack_size: Package size
- barcode: Product barcode
- nutritional_info: Nutritional information
- manufacturer_details: Manufacturer information
- shelf_life: Product shelf life
- storage_instructions: Storage requirements
- fssai_printed: FSSAI printed flag
- return_policy: Return policy information
- apob_registration: APOB registration number
- batch_number: Batch number
- tcs_gst_compliant: TCS GST compliance status

Local JSON Fallback Structure:

Users JSON Structure:
- users: Array of user objects with id, email, password_hash, role, name, phone

Orders JSON Structure:
- orders: Array of order objects with order_id, buyer_id, seller_id, status

Products JSON Structure:
- products: Array of product objects with product_id, name, price, category
